# 智能桌面整理 Agent：演示手册

## 演示目标

在约 5 分钟内证明三件事：Agent 能理解跨专业文件内容，能通过多个角色协作生成动态整理计划，并且没有用户批准就不会移动文件。

## 演示前准备

在终端依次运行：

```bash
# 先进入你自己的项目目录
source .venv/bin/activate
python scripts/build_showcase_demo.py
export OPENAI_API_KEY="请替换为自己的 API Key"
python -m streamlit run app.py
```

生成脚本会重建 `showcase_demo`，因此每次演示前都能恢复到相同初始状态。不要在这个目录保存自己的文件。

## 五分钟展示流程

### 1. 介绍问题（约 30 秒）

可以这样说：

> 普通桌面整理工具通常只能按扩展名分类，无法判断“这张截图是线性代数课件”或“这份文档属于民事诉讼法”。这个 Agent 会结合文件名、正文、图片内容和课程知识，生成适合当前文件集合的动态分类方案。

### 2. 展示多 Agent 分工（约 40 秒）

指出首页六张卡片：扫描、内容理解、课程知识、规划、安全审查和执行。强调它们共享 LangGraph 状态，但只有需要语义判断的节点调用模型，避免不必要的费用。

### 3. 运行智能分析（约 90 秒）

1. 确认目录为 `showcase_demo`。
2. 在“整理范围”中选择“全选”，或手动勾选若干项目。
3. 开启“读取文档与图片内容”。
4. 点击“开始智能分析”。
4. 等待结果出现。

重点观察：

- 法学、微电子、医学、金融、文学、数学等文件能形成跨专业分类。
- 文件名只有“课程资料”“实验记录”“课堂截图”等中性信息，课程判断来自正文或图片内容，而不是文件名。
- `20260001_示例学生_实验5` 文件夹和 `提交材料_10.zip` 会根据内部 Word 实验报告识别课程，并作为整体整理。
- `17-智能体` 会读取第三层的 `实验报告.docx`，识别为人工智能课程资料。
- 三张 PNG 的“内容状态”为 `extracted`，说明模型实际理解了图片。
- 无扩展名的“待确认文件”应保留给人工判断。
- “多 Agent 协作轨迹”显示每个 Agent 做了什么。

### 4. 展示安全预演（约 60 秒）

指出“执行预演”中的源文件和目标位置。此时文件尚未移动，目标目录也尚未创建。

强调四道安全控制：

- GPT 只生成结构化计划，不接触文件系统。
- 本地验证器检查文件 ID、类别关系和完整性。
- 安全审查 Agent 检查路径越界、覆盖和置信度。
- 最后必须由用户点击确认。

### 5. 执行并查看结果（约 40 秒）

点击“确认并执行整理”。网页显示成功移动数量后，在 Finder 中查看 `showcase_demo` 下新生成的分类目录。

整理成功后，左侧会出现“撤回上次整理”。点击即可将本次移动的文件恢复到原位置，并清理 Agent 创建的空目录。撤回前系统会重新验证文件没有被修改、原位置没有被占用。

如果不想现场修改演示目录，可以点击“取消本次整理”，同样能够证明人工中断机制有效。

### 6. 总结（约 30 秒）

可以这样说：

> 这个项目不是让大模型直接操作电脑，而是让模型负责理解和规划，让确定性的本地程序负责验证和执行。它兼顾了动态分类能力、跨专业适用性与文件操作安全。

## 常见问题

### 为什么不让六个 Agent 都调用一次 GPT？

扫描、知识检索、安全检查和移动文件属于确定性任务，本地程序更便宜、更快、也更可靠。GPT 主要用于图片理解和整体语义规划。

### 198 门课程仍不可能覆盖所有专业怎么办？

课程库只是保守提示，不是分类白名单。命中时提供标准课程名；没有命中时仍由 GPT 根据内容动态创建类别。

### 为什么要人工确认？

文件移动属于有副作用的操作。LangGraph 在执行前暂停，只有收到明确批准才继续，避免模型误判直接改变用户文件。

### 图片或模型请求失败怎么办？

图片理解失败会降级为文件名和元数据分类；信息不足的文件进入人工确认，不会阻塞其他文件。

## 现场故障兜底

- 网页没有自动打开：访问 `http://localhost:8501`。
- 提示未配置 Key：在启动 Streamlit 的同一个终端重新执行 Key 配置命令，再重启应用。
- API 限流或余额不足：展示已有截图，并运行 `python -m pytest -q` 证明本地安全链路正常。
- 演示目录已经整理过：重新运行 `python scripts/build_showcase_demo.py`。
- 不想消耗图片 token：关闭内容读取，仍可展示元数据分类、多 Agent 轨迹和安全预演。
